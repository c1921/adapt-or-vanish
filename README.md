# 适者延续 · Adapt or Vanish

物种演化主题的单机 Roguelike Deckbuilder 原型。通过性状表达应对食物、温度和捕食压力，将反复成功表达的性状固化，让谱系穿过干旱。

## 本地运行

已在 Node.js 24.12、npm 11 环境验证。

```sh
npm install
npm run dev
```

打开终端给出的本地地址。界面为中文，不需要账户或后端；进度保存在当前浏览器的 localStorage 中。清除浏览器数据、更换浏览器或更换站点地址不会携带原存档。

```sh
npm test              # 确定性规则、内容、完整单局及存档测试
npm run build        # Vue / TypeScript 检查与生产构建
npm run preview      # 预览 dist 中的生产构建
npm run format:check # 代码格式检查
npm run format       # 格式化源代码与文档
```

## 已实现

- 24 个世代：森林 8 代、草原 8 代、逐步加剧的干旱 8 代。
- 30 种性状、五种分类、三组共七条分支突变。
- 每代五张手牌、三点表达额度，可反复选择并预览准确的结算结果。
- 卡牌游戏式棋盘：顶部 HUD（生态旅程 / 威胁意图 / 牌堆抽屉）、中央舞台（事件、物种、生存预测）、底部常驻手牌区，页面不整体滚动。
- 竖版卡面按性状分类配色，带费用宝石、插画槽、规则文本框、结果条与固化进度条；悬停抬牌并即时预览结果，每张牌标出多救活多少个体。
- 键盘可用：手牌区方向键移动、空格切换、演化选择按 1/2/3、Esc 关闭抽屉与跳过。
- 种群出生与压力损失；植物、昆虫、小型动物三种有限资源。
- 同名性状每代最多累计一次表达；表达后存活即计次，五次后可主动固化。
- 六个永久性状槽位，固化移除全部同名副本，收益与代价从下一代生效；永久性状会组成物种身份与生态描述。
- 每两代一次演化选择，新性状、分支突变或跳过。
- 确定性种子、逐步自动存档、断点继续、终局记录与演化时间线。
- 深色棋盘配语义色与图标/文字双重编码，支持窄屏；动效遵循 `prefers-reduced-motion`。

初始祖先种群为 120。单局 15～25 分钟是设计目标，实际时长取决于阅读和决策速度，尚未经玩家样本验证。

## 代码结构

```text
src/game/           纯 TypeScript 规则、类型、内容和随机数
src/game/analysis.ts  展示用的派生计算：基线对比、单卡增量、悬停预览、威胁分级、时间线合并
src/game/species.ts   永久性状到物种身份的描述词表与句子生成
src/game/theme.ts     卡面分类配色与每种性状的插画字形
src/persistence/    带版本号的存档、运行时校验及存储接口
src/composables/    Vue 与引擎、存储之间的薄适配层
src/components/     首页、棋盘外壳（RunView）与各阶段面板
src/components/board/  卡面、手牌区、HUD、意图、抽屉、种群圆盘、数字滚动
tests/              单元测试、展示层派生计算、组件渲染冒烟、完整单局策略和存档恢复测试
docs/               当前规则与扩展指南
```

规则层不依赖 Vue、DOM 或浏览器存储。预览与结算共享同一函数；随机状态显式保存在单局状态中。展示层的派生数据（"这张牌能多救活多少个体"、"悬停后种群会变成多少"、"这一代的威胁等级"）全部通过调用 `previewGeneration` 得到，组件里不存在第二套规则。

## 验证与后续

测试包含 `shelter-01` 与 `fertility-01` 两个固定种子的策略回归：形成不同永久性状组合并通关。测试中的自动策略只是开发期的数值检查工具，不会出现在实际游戏中，也不代表所有随机局都保证获胜。

后续可沿内容与规则层扩展分支地图、新祖先、生态位竞争、局外解锁等。第一版没有年龄结构、多物种 AI、完整遗传学或系统发育树，这些属于创意文档的后续方向。
