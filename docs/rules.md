# 首版规则

本文记录当前实现。创意文档中的完整生态模拟、物种分化和局外成长属于后续方向，不参与本版结算。

## 单局与阶段

起始祖先为原始小型四足动物，种群 120，初始牌组 10 张。初始牌组包含重复性状，不同副本具有独立卡牌 ID。

环境依次为森林、草原和干旱期，各持续 8 代。森林为寒冷环境，草原与干旱期为高温环境。干旱期第 1、4、7 代分别进入新的压力阶段。

状态机：

```text
adaptation → settlement → adaptation
                      ↘ evolution → adaptation
adaptation → ended（灭绝，或完成最终世代）
```

每代开始时先确定并公开事件，再抽牌。环境基值和资源经过事件修正后限制在 0～10；性状的额外负担可以让结算前的压力超过 10。预览不消耗随机数。

## 表达与资源

- 每代抽五张，表达额度三点。牌的费用是一或两点。
- 选牌可撤销，费用超额时不能继续选择；也允许零张结算。
- 表达与永久性状一起汇总，按温度与性状标签判断条件，然后统一计算效果。因此不依赖点击顺序。
- 多张牌采集同一种资源时先合计，再以本代可用资源为上限；资源没有优先抢占顺序。
- 三类采集资源各按 1:1 转为本代食物供应，抵消食物压力。不跨代累积食物资源。
- 世代结算后所有手牌进入弃牌堆。抽牌堆耗尽才洗入弃牌堆，同一代不会重复抽同一卡牌实例。牌组不足五张或为空时仍可继续。

## 种群

设剩余食物、温度、捕食压力为 `F/T/P`，性状繁殖修正为 `B`：

```text
出生 = max(0, 8 + B - F)
食物损失 = 2F
温度损失 = 2T
捕食损失 = 2P
下一代种群 = max(0, 当前种群 + 出生 - 总损失)
```

压力抵消后的最低值为零。如果损失超过本代可用种群，则总死亡以当前种群加出生为上限，按三个压力的损失比例分摊，余数按小数部分从大到小补齐。这样灭绝代的损失明细仍与实际种群变化一致。

首版不设置种群上限，所有个体数与效果量使用整数。所有系数位于内容配置的 `rules`。

## 固化

只要表达了该性状，并且结算后种群大于零，就增加一次表达进度。无须本代净增长，也不要求效果确实抵消压力。同名性状共享进度，同代打出多个副本只增加一次；灭绝代不增加进度。

累计五次后，在任意非终局的世代结算阶段可主动固化，也可推迟。固化会移除全部同名实例并占用一个永久槽位。永久效果与代价从下一代开始生效，不回写刚完成的结算。

最多六个永久性状，不叠加同名永久性状，首版不能替换或撤销固化。达到上限后仍能正常获得牌、突变和推进世代。

## 新牌与突变

第 2、4、…、22 代结算后提供三个候选，可选择一项或跳过。如果有合法突变，至少一项为突变，其余为不同的新性状候选。没有合法突变时全部为新牌；自定义内容池不足时显示实际可用数量，始终允许跳过。

新牌添加独立实例并进入弃牌堆，可以获得已持有的同名普通性状。已固化性状不再作为新牌奖励出现。

突变针对一个源卡实例，替换它的性状，保留实例 ID 与所在牌区。目标尚未持有也未固化时才合法，目标的表达进度归零，其他源卡副本保留。分支性状默认不进入普通新牌池。

当前分支组：

- 灵活前肢 → 翼 / 利爪 / 挖掘肢。
- 体毛 → 厚毛 / 稀疏体毛。
- 快速成熟 → 大量后代 / 精细育幼。

## 终局与保存

种群归零优先判定灭绝；最终代仍有种群则通关。终局不再发奖励或进行固化。记录完成世代、最大种群、环境、固化、突变及逐代结算，不模拟真实地质年代。

每次有效操作均保存，包括选牌、固化与奖励选项。刷新先回到首页，选择继续即可恢复原阶段。存档包含随机流状态，恢复不会刷新手牌、事件或奖励。

存档损坏、版本不兼容、浏览器禁用存储或写入失败时显示提示。不会自动删除坏存档；用户开始新谱系时才覆盖。存储失败不阻止当前内存中的游戏继续。
